# Starbie-

<img width="1309" height="864" alt="image" src="https://github.com/user-attachments/assets/9433b0ab-f608-407a-b048-eed899ef4606" />

This is an adaptation of the regular starter project "starbie" for Hackclub, Half-Life. I have added an extra button for more controls, a terminal and connections for a battery to attach to the board so that it can be made portable. The controls are mapped to the same buttons, with the top button being bound the same as the right, as I happened to run out of time working on this project. I did not add keycaps as I personally like the switches without the keycaps, but if you want, feel free to add them.
