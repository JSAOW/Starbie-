# Starbie-

<img width="1309" height="864" alt="image" src="https://github.com/user-attachments/assets/9433b0ab-f608-407a-b048-eed899ef4606" />

This is an adaptation of the regular starter project "starbie" for Hackclub, Half-Life.
I added an extra button for more controls, a terminal, and battery connections so you can attach a battery to the board and make it portable. 
The right controls map to the same buttons, with the top button bound the same as the right, and I added a square trail because I ran out of time on this project to do much more (along with me not knowing C++ very well). 
I did not add keycaps as I personally like the switches without the keycaps, but if you want, feel free to add them. 
If I were to do this agan, I would probably add more functionality through the code such as adding a new menu with the extras button instead of having two buttons do the same thing (I dont know how to code that well) and add more art/customise it more.
